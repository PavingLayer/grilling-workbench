# Working agreements

Before designing or implementing the workbench, read [README.md](README.md) for
the agreed requirements, integration boundary, and open design questions.

Keep workbench changes in this repository. Inventor is a separate project; its
source and interview documents are outside this project's change scope.

Commit every change to tracked files immediately. Use small, coherent edits and
commit them before starting unrelated work or yielding. Preserve unrelated user
changes; if a commit is blocked, report it instead of silently leaving work pending.

Only explicit user decisions settle requirements. Recommendations, drafts,
clarification requests, and silence are not consent.
